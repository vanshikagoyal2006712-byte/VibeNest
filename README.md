
# VibeNest – Smart Flatmate Compatibility & Matching Platform

## About the Project
VibeNest is a web application designed to help individuals find compatible flatmates based on their lifestyle, daily habits, cleanliness preferences, and budget.

The platform collects user preferences, compares them with other profiles, and helps users discover potential flatmates with similar living preferences.

## Problem Statement
Finding a suitable flatmate can be challenging because people may have different routines, budgets, cleanliness standards, and lifestyle choices. VibeNest aims to make this process easier through preference-based matching.

## Key Features
- User authentication using Firebase Authentication
- Collection of flatmate preferences
- Lifestyle-based compatibility matching
- Compatibility scores and profile ranking
- Firebase Realtime Database integration
